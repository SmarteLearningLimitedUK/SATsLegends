# SATs Legends universe homepage

The homepage introduces both Matharia and Lexcoria at equal prominence, links to each adventure, and moves the detailed world introductions above the general revision overview. Lexcoria artwork comes from the existing pinned English game build; availability wording follows the existing release settings. The shared purple, blue and gold palette remains in place.

Changed files: `src/website/HomePage.tsx`, `src/website/website-cinematic-hero.css`, `src/assets/website/lexcoria-world.webp` and this report. Assumptions: retain existing game access and subscription rules, and treat the website as a companion to classroom learning. No external legacy assumptions were used.

Verification: TypeScript passed, and Chromium emulation at 320, 390, 768 and 1440 pixels checked both adventure links, artwork loading and horizontal overflow. Physical-device testing was not performed.
