# Sats Legends

Sats Legends is the active React + TypeScript + Vite app in this repository.

## Run locally

1. Install dependencies:
   - `npm install`
2. Start dev server:
   - `npm run dev`
3. Build:
   - `npm run build`

## Active structure

- `src/`

  - `components/`
  - `games/`
  - `layout/`
  - `screens/`

- `public/`
