SATs Legends Antigravity Upload Package

This bundle consolidates the accessible project files, licensed UI atlases, pre-sliced assets, reference sheets, and Gemini controller documents into one upload-ready package.

Folder guide:
- 01_project_builds: project zip milestones, including the latest bespoke icons/playfields pass.
- 02_asset_atlases_raw: raw licensed atlas files and background art.
- 03_pre_sliced_assets: cropped assets already broken out from the atlas pack.
- 04_backgrounds_and_refs: contact sheets and reference/inspiration images.
- 05_gemini_controller_docs: prompt/controller documents for Gemini-based asset generation.
- 06_notes: this README and manifest.

Recommended starting point:
1. Use 01_project_builds/Satsgamecombo-main-bespoke-icons-playfields.zip as the latest project baseline.
2. Import the raw atlas files from 02_asset_atlases_raw into Antigravity as source art.
3. Use 03_pre_sliced_assets immediately for quick UI replacement where helpful.
4. Use the Gemini controller docs only for generating missing characters, bosses, and bespoke assets.

Important:
- These project zips were packaged during iterative passes and were not fully runtime-verified in this environment.
- The licensed UI images were provided by you and are included here as source assets.
- Some previous files created earlier in the conversation may not be represented if they were not present in the accessible working directory.
